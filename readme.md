# Processo de trabalho - Parte A

Para desenvolver este trabalho, comecei por analisar o quadro de Mondrian, procurando perceber melhor a sua composição, as proporções e a forma como as linhas dividem os diferentes espaços. Para a Parte A, recorri ao Illustrator, onde consegui observar com mais precisão as tonalidades utilizadas, consultar os códigos das cores e identificar a localização das linhas pretas. Utilizei também as dimensões reais do quadro como referência, de modo a compreender melhor os tamanhos dos retângulos e os espaços entre as divisões.

Depois desta análise, passei para o p5.js, onde comecei a construir o código através de formas geométricas simples. Fui definindo as coordenadas, as dimensões e as cores de cada retângulo, procurando aproximar o resultado o mais possível da imagem original. Ao longo do processo, foi importante ajustar alguns valores e perceber como a posição e a espessura das linhas influenciavam o resultado final. O objetivo foi reproduzir a composição de forma rigorosa, respeitando as proporções e o equilíbrio visual característicos da obra.
